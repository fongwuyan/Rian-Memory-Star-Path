# 发布检查清单（v0.0.1）

自动检查先跑：

```powershell
node rian-memory-star-path/tests/regression.mjs
node rian-memory-star-path/tests/theme-contrast.mjs
```

`regression.mjs` 需要 DSH Web GUI 与插件正在运行。

## 1. 安装与入口

- [ ] 插件启用后，侧边栏出现「雨咯记忆星」
- [ ] 首次打开出现欢迎层，点击「开始使用」后不再出现
- [ ] 输入框左侧出现绑定 chip，可切换「公共 + 项目」/「仅公共」
- [ ] 设置页出现「雨咯记忆星」选项卡

## 2. 主题

- [ ] 深色主题：主面板、详情、搜索、归档、弹窗、设置页正常
- [ ] 浅色主题：上述界面无漏改深色块，文字对比度正常
- [ ] 切回深色后颜色恢复
- [ ] 主画布保持星空深色，星点与标签可见

## 3. 核心流程

- [ ] 对话里「记住：…」能写入当前项目图
- [ ] `memory_search` 能召回；无答案问题返回空
- [ ] 公共图写入进入星云待确认
- [ ] 星云批量点亮 / 丢弃正常
- [ ] 编辑模式可建星、改星、归档、删除
- [ ] 冲突星出现横幅，三种裁决正常
- [ ] 星尘可查看、可恢复旧版本
- [ ] 归档按钮可查看、恢复、永久删除
- [ ] 导出当前图 / 全部 zip 可解压，含星尘历史
- [ ] 导入同名弹窗可选副本 / 合并 / 取消
- [ ] 自动备份生成，最多保留 5 份

## 4. 10k 规模

准备一个 10k 星 zip（可用 `zip.js` 生成）并从设置页导入：

- [ ] 导入成功，星图可打开
- [ ] 首屏布局完成（Worker 约 2s 内）
- [ ] 缩放/拖拽（沉浸模式）与滚轮切图不卡死
- [ ] 全局搜索「万星」返回结果
- [ ] 打开星详情、归档、搜索弹窗正常
- [ ] 记录 `GET /health` 的 `lastSearchMs`

参考：本机 10k 热检索 p95 约 9.8ms，布局 Worker 约 1.76s。

## 5. 隐私

- [ ] 敏感过滤标准 / 严格 / 只拦凭据可切换
- [ ] 自定义敏感词生效
- [ ] 隐身模式停止写入与召回
- [ ] 项目图顶部「暂停」后该工作区写入/召回停止
- [ ] 输入框 `⏸` 后该会话写入/召回停止
- [ ] 导出前提醒默认开启

## 6. 备份与恢复

- [ ] `backups/` 有 zip，数量不超过 5
- [ ] 关闭自动备份后重启不再新增
- [ ] 导出的 zip 重新导入后星数、历史、状态一致
- [ ] 恢复默认设置只重置设置，不删数据
